# Codex Workflow

1. Read authoritative documents.
2. Inspect the repository and environment.
3. Plan one bounded task.
4. State expected files, tests and risks.
5. Implement.
6. Run validation.
7. Report evidence and limitations.
8. Stop at the active milestone boundary.

Parallel agents may work only on non-overlapping ownership areas. One coordinating agent owns integration.

## Cross-platform evidence

For applicable milestones, validate Android and a locally served Web build separately. Editor success is not browser compatibility evidence.

## Milestone 0 evidence rule

Milestone 0 verified Unity `6000.5.6f1`, Android/Web build modules, project creation, Unity tests, Android device smoke and local Web browser smoke. Preserve exact command/output evidence and keep later gameplay, networking, public hosting, store and release-signing approval gates explicit.
