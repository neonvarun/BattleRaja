# Milestone 1 Report — Cross-Platform Movement Laboratory

## Gate status

**Provisional pass.** The technical gate passed; subjective feel, touch ergonomics,
and camera preference remain human-review debt. No combat, bots, networking,
backend, progression, or final art was added during M1.

## Implemented

- Pure movement/aim domain model with validated tuning, acceleration, deceleration,
  max speed, aim persistence, and command creation.
- Unity movement agent, desktop/Web input adapter, Android virtual sticks, safe-area
  panel, aim indicator, and configurable top-down camera.
- Grey-box MovementLab scene with reusable materials and a serialized movement-tuning
  asset.
- Separate Android and Web development build entry points.

## Evidence

- Unity `6000.5.6f1`, URP `17.5.0`, Input System `1.20.0`, uGUI `2.5.0`, and Test
  Framework `1.7.0` remained pinned.
- EditMode: 8/8 passed (`Builds/M1/TestResults/editmode.xml`).
- PlayMode: 7/7 passed (`Builds/M1/TestResults/playmode.xml`).
- Editor project validation passed.
- Android IL2CPP ARM64 APK built and launched on Lava API 34 and Oppo API 36;
  final smoke logs reported zero application exceptions.
- WebGL2/WebAssembly build succeeded, served over local HTTP, and exposed Unity
  bootstrap content in Chrome 150 and Edge 150.
