## Implemented safe preparation

- `ServerMatchConfig.M9Proof` defines the intended client-server alpha envelope: eight
  slots, 30 server ticks per second and a bounded reconnect grace period.
- `AuthoritativeMatchServer` is a transport-independent Infrastructure preparation seam
  that starts an offline domain match, validates protocol/room capacity, backfills vacant
  slots with bots, clamps movement input, owns authoritative health/elimination calls and
  models disconnect grace, reconnect and bot takeover states.
- The server preparation owns canonical `OfflineMatchSimulation` snapshots; it does not
  expose client-controlled position, damage or result mutation. It is not a headless
  deployment and has no Photon/PlayFab dependency.
- Four EditMode proof tests cover eight-slot backfill, movement/stale-input validation,
  grace/reconnect/takeover and idempotent server-authority damage.
