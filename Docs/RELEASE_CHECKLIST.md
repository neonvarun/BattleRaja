# Release Checklist

This is a future checklist, not a declaration of readiness.

- Tests and Android build
- Device matrix
- Performance evidence
- Crash/ANR review
- Secrets scan
- Permissions review
- Data Safety and privacy
- Third-party licences
- Content rating
- Target API compliance
- Account deletion where applicable
- Cultural/naming review
- Store assets and truthful description
- Known issues

## Web release

- Supported-browser matrix
- HTTPS and compatibility/error page
- Compression, MIME and cache headers
- CDN and cache invalidation
- Initial download and WebAssembly memory budgets
- Desktop browser regression suite
- Cross-play compatibility
- Background-tab/reconnect behaviour

## Milestone 0 limitation

This checklist is not a release declaration. Milestone 0 may produce only development artifacts and local smoke evidence; it does not establish store, public hosting, signing, performance, privacy, browser-completeness or production readiness.
